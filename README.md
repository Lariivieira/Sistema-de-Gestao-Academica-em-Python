# Sistema de Gestão Acadêmica em Python
Projeto acadêmico desenvolvido em Python com o objetivo de implementar um sistema completo de gestão acadêmica utilizando conceitos fundamentais de programação.

O sistema realiza as quatro operações básicas (CRUD – incluir, listar, atualizar e excluir) para os módulos de estudantes, professores, disciplinas, turmas e matrículas, permitindo o gerenciamento completo das informações acadêmicas.

Foram aplicados conceitos como uso de estruturas condicionais (if/elif/else), estruturas de repetição (for/while), listas e dicionários para organização dos dados, funções para modularização e reaproveitamento de código, além de persistência de dados em arquivos.

O projeto também conta com validações para evitar duplicidade de códigos (como em turmas e matrículas) e tratamento de exceções com try/except, garantindo maior controle e estabilidade na execução do sistema.
